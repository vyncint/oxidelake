# Code of Conduct

Everyone participating in this project — in issues, pull requests, reviews and
discussions — is expected to be respectful, constructive and honest.

- Assume good faith; critique code and ideas, not people.
- Keep discussions technical and evidence-based (this project's honesty rule
  applies to claims about people's work as much as to claims about GPUs).
- Harassment, discrimination and personal attacks are not tolerated.

Maintainers may edit, remove or lock contributions that break these
expectations. Concerns can be raised privately through GitHub's report feature
on this repository.
